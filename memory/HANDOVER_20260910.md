## 2. Skript-Fakten
- Zweck: zeigt den Kontext-Füllstand des DeepSeek-Web-Chats als schwebendes Badge.
- Technik: Hook auf `window.fetch` + `XMLHttpRequest.prototype.send`, liest
  `data.biz_data.chat_messages[].accumulated_token_usage` aus `*/chat/history_messages`,
  zeigt das **Maximum** der Werte. `@grant none`, `@run-at document-start`, `@noframes`,
  `@match https://chat.deepseek.com/*`.
- `CONTEXT_SIZE = 1000000` (V4-Kontextfenster, im Skript konfigurierbar), `DEBUG`-Flag.
- Keine externen Calls, keine Persistenz, kein Tracking.

## 3. Wichtige Entscheidung: Metablock lokalisiert (v1.0.0 → v1.0.2)
Ausgangslage: `@name:de` + `@description` (EN) + `@description:de`.
Umgestellt auf die immerzu-Konvention:
- `@description` = **DE** (bestimmt die GF-Skript-Locale), dazu `@description:en` + `@description:ru`.
- **`@name:de` entfernt** — GF verlangt zu jedem `@name:xx` ein passendes `@description:xx`;
  der Produktname ist in allen Sprachen identisch.
- Grund (am GF-Quellcode verifiziert, `app/models/script.rb`): Der suffixlose `@description`
  wird Default, die Skript-Locale entsteht per Spracherkennung (`set_locale` → `detect_locale`);
  `update_localized_attribute` enthält `next if meta_locale == locale` — ein `@description:de`
  wird also **ignoriert**, wenn DE die Default-Locale ist. Nur echte Fremdsprachen-Suffixe
  erzeugen zusätzliche Lokalisierungen (→ Auffindbarkeit in `/de|en|ru/scripts?q=…`).
- Keine funktionalen Skriptänderungen; nur Metablock + Init-Logzeile.
